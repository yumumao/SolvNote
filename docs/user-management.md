# 用户系统：部署、边界与本地验收

> 2026-09-27用户确认本地真实验证成功并授权推送GitHub。本文件说明当前源码的部署要求，不代表镜像或演示站已升级；线上验收必须单独进行。

## 升级前必须做的事

1. 保持公网注册关闭。停止写入，成套备份SQLite数据库、配置目录和原环境变量，尤其是`NEXTAUTH_SECRET`与AI主钥。不要新建空卷替代旧卷，不要换主钥。
2. 在Cloudflare创建Turnstile站点，允许实际站点hostname。服务器填写`SOLVNOTE_TURNSTILE_SITE_KEY`、`SOLVNOTE_TURNSTILE_SECRET_KEY`、实际HTTPS的`NEXTAUTH_URL`；可选`SOLVNOTE_TURNSTILE_HOSTNAMES`为逗号分隔的精确hostname，不含协议/端口/通配符。Site key可以公开，secret只在服务器保管。登录和注册分别校验`login`与`register`action。
3. 缺配置、错误hostname/action、验证服务超时或失效令牌都拒绝请求。不要在生产添加绕过验证的开关。若配置错误，用部署平台修正环境并重启，而不是删库或改用户密码。真实Cloudflare验证需人工联调，自动化mock测试不能代替它。
4. 保持`SOLVNOTE_ENABLE_AI_CONFIG_EXPORT=false`或不设置。它只有trim后忽略大小写等于`true`才恢复管理员导出，`1`、`yes`等不会开启。普通用户始终不能导出站点AI配置。模板是公开无密钥静态文件，不是配置备份。
5. `SOLVNOTE_TRUST_PROXY_HEADERS`默认false。只有源站无法绕过受控反代、且反代覆盖客户端IP头时才能启用；不能仅凭使用了Cloudflare DNS就信任这些头。默认始终按账号限流并强制Turnstile；只有显式信任且格式正确的IP才加每IP桶，不把未知来源合并成全站限流桶。
6. 仅在批准升级后，在备份副本验证`npx prisma migrate deploy`，再按正式发布流程迁移。迁移只新增字段/表，不追溯已有账号期限。本轮未运行真实库迁移。
7. 启动后先测试管理员登录、权限编辑、普通账号登录与改密，再在管理界面显式开启注册。需要公网试用时，先选默认AI、设定邀请策略，再开放。

## Zeabur环境变量与多个公开域名

已有站点升级只需补齐新的验证配置，原会话密钥、数据库和AI主钥必须保留。不要整份复制本地隔离测试的.env.local到线上。

|变量|已有站点的配置方式|
|---|---|
|`NEXTAUTH_URL`|一个规范主站URL，建议`https://solvnote.n29.net`；不是地址列表，不含`/login`。|
|`NEXTAUTH_SECRET`|保留当前强随机值。`AUTH_SECRET`是框架别名，无需另设；当前版本优先使用`NEXTAUTH_SECRET`，两项都保留时建议保持一致。|
|`SOLVNOTE_TURNSTILE_SITE_KEY`|新增必填，使用生产Turnstile组件的Site Key。|
|`SOLVNOTE_TURNSTILE_SECRET_KEY`|新增必填，同一组件的Secret Key，仅保存在平台秘密变量。|
|`SOLVNOTE_TURNSTILE_HOSTNAMES`|可选；默认取主站hostname，建议显式填`solvnote.n29.net`。无协议/端口/路径/通配符。|
|`SOLVNOTE_ENABLE_AI_CONFIG_EXPORT`|保持`false`或不设置，禁止所有用户的AI配置导出。|
|`SOLVNOTE_TRUST_PROXY_HEADERS`|默认`false`；只有满足上面的可信反代条件才启用。|
|`DATABASE_URL`|保留原路径；当前官方容器缺省为`file:/app/data/dev.db`，不要为升级换库。|
|`INITIAL_ADMIN_EMAIL`/`INITIAL_ADMIN_PASSWORD`|仅新库无管理员时初始化用，不会重置已有管理员；不要填本地测试账号。|
|`AI_CONFIG_MASTER_KEY`/`AI_CONFIG_DIR`|已有配置保持原值。未设环境主钥时保留`/app/config/ai-master.key`与配置持久卷，不能生成替代主钥。|

`/app/data`和`/app/config`均须持久化。生产不要启用`AI_WORKER_DISABLED=1`，不要复制本机代理变量。默认AI、逐用户AI授权、注册开关、邀请码与账号期限在管理界面/数据库设置，不是额外必填环境变量。

**多域名不是多NEXTAUTH_URL。**当前安全策略只信任主站Origin，建议把其他公开域名在Cloudflare或可信反向代理上跳转到主站，并保留路径和查询参数；应用只处理本地localhost/127.0.0.1别名，不会自动重定向公网域名。若需要多个域名都独立登录并完整操作，须另行设计可信Origin白名单与会话策略，不应通过拼接NEXTAUTH_URL或放松同源校验实现。

Cloudflare组件可添加多个允许的hostname；服务端`SOLVNOTE_TURNSTILE_HOSTNAMES`也可逗号分隔多个精确hostname。但两者只允许验证码使用/验证，并不改变本站同源策略，不能仅凭增加Turnstile域名宣称多域名已经完整可用。建议本地与生产使用不同组件，生产组件不保留localhost。

先填好云端变量并备份，再明确发布/切换镜像与重部署，最后从主站测试登录、用户管理与AI写入；保持注册关闭直到配置默认AI和邀请策略完成。

## 用户管理

- 注册关闭是数据库默认值，旧`allowRegistration`设置不能再打开注册。
- 自注册默认7天，可改7天/30天/永久；手建账号默认永久，支持同样期限选择。到期时刻相等也算过期。
- 管理员可创建、禁用、续期、重置密码和删除用户；敏感变更带revision防并发覆盖。不能自禁用、自删除或自降级，最后可用管理员受保护。
- 新建/重置返回临时密码，仅当次显示，不写列表、日志或邀请接口。用户必须用当前临时密码设置新密码，随后重新登录；旧会话失效。
- 新密码至少15字符且不超过72个UTF-8字节。原有短密码仍能登录，修改时适用新策略。
- 邀请码默认30天、1次。可续期、调整最多使用次数或停用；续期不恢复已消耗次数。删除操作停用邀请码并保留使用审计，不悄悄删除历史记录。
- 只有显式选择邀请码并开启公开显示，注册框才自动填入有效、未耗尽的码。开启意味着任何访客都可看到它，不能再将它当作秘密准入凭据。

## AI权限与导入

- 管理员选择3项新账号默认模型（可用模型不足3项时全选），并可授予更多模型给指定用户。默认值变更不追溯重写现有授权快照。
- 旧账号一次性获得迁移兼容授权，此后撤权不会因再次访问而重新补回。新账号不走旧账号回填。
- 用户的个人AI与站点AI分开存储及运行时命名。个人编辑和导入只影响本人；站点密钥不能通过列表、错误信息或个人导入读取。
- 站点导入入口在管理员AI设置，个人导入入口在个人AI设置。下载`/api/ai/config/template`或`docs/templates/solvnote-ai-config.template.json`，填写自己的值；模板没有真实密钥，默认停用。明文模板导入不需口令，加密文件仍需原口令。
- 管理员站点导入先预览、后确认；确认令牌绑定用户、内容和配置版本。个人导入是一次严格校验和版本CAS提交，合并/替换仅影响自己的配置。任何版本冲突都需重新加载，不强制覆盖。
- 关闭导出不等于管理员账号泄漏后万无一失。泄漏管理员仍可能调用AI、修改连接与用户；请使用独立长密码、保护部署账户及数据库/主钥备份。

## 到期与删除

- 到期/禁用/旧版本会话无法访问受保护页面和API；公开登录、注册状态、无密钥模板和静态资源不包含个人数据。
- 到期满30天后，清理任务启动时运行一次，此后每小时运行，每批最多100人。停机后会追赶清理；大积压会分批处理，不承诺到第30天的秒级删除。
- 最后一个管理员恢复账号不自动删除，但仍受到期/禁用限制，不会自动续期或开放登录。
- 当前附件是数据库里的data URL或AI任务/会话载荷，没有受管上传目录。清理删除用户拥有的数据及无外键的AI任务；不会按导入URL去抓取或删除磁盘文件，也不动AI主钥或配置目录。审计保留无凭据事件；旧备份中的数据需运维另行清理。
- 永久删除不能通过续期恢复，部署前必须认可保留周期并备份。回退时使用配对的发布版本、数据库备份与原主钥，不对真实数据运行reset。

## 兼容变化与验收清单

旧Openclaw批量上传不再接受API key/用户名密码作为独立登录入口，必须带有效站点会话，只能写本人账号。`/api/user`不再接受password字段，改密使用`/api/user/password`并提供当前密码。旧客户端需要相应调整。修改邮箱会撤销已有会话并要求重新登录，避免旧邮箱被他人注册后出现身份错配。

- [ ] 真实Turnstile：登录/注册成功，过期/重复/错误action或hostname被拒绝。
- [ ] 注册默认关闭；邀请码过期/耗尽/停用不能注册，续期和公开显示符合设置。
- [ ] 新账号7天、手建永久、既有账号不变；禁用/到期/重置后的旧会话无效。
- [ ] 默认3项与额外授权可用，撤权后排队任务和会话结果不泄漏；用户私有配置隔离。
- [ ] 管理员及普通用户都不能导出；空模板可导入且不含部署凭据。
- [ ] 在临时数据库验证30天清理及最后管理员保护。
- [ ] 电脑/手机后台操作及一份完整备份恢复演练。

这些部署验收项不因自动化单元测试通过而自动打钩。本地人工验证通过不代表生产数据迁移、线上注册或各项权限边界全部验收；线上操作仍须单独授权并备份。
