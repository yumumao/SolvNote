# 安装到手机

解迹可以添加到手机主屏幕，以独立应用窗口打开。安装入口位于首页和登录页底部，点击“安装应用”查看说明；浏览器允许直接安装时，还会出现“安装到设备”按钮。安装免费，AI调用仍遵循原有设置与计费规则。

## 安卓

用Chrome打开网站，点击页脚“安装应用”，如出现“安装到设备”按钮即可使用。也可以从浏览器菜单选择“安装应用”或“添加到主屏幕”，按系统提示完成。不同浏览器的菜单名称可能不同。

## iPhone / iPad

用Safari打开网站，点“分享”→“添加到主屏幕”。如显示“作为网页App打开”，保持开启，再点“添加”。随后从主屏幕图标打开。

在微信等应用内打开时，先选择用系统浏览器打开。未显示安装选项也可以继续使用网页版。已从独立应用窗口打开时，页脚安装入口自动隐藏。

## 使用边界

- 使用时需要联网；现有登录、识图、解题、绘图、分享与任务恢复流程保持不变。
- 安装后如果看到登录页，使用原账号登录即可。安装不会创建新账号，也不会复制已有学习记录。
- 应用绑定安装时使用的网址。主站、别名及自行部署的网站属于各自的浏览器应用，不应混淆其登录状态。
- 不加入离线缓存或后台重试，不注册Service Worker，不在安装流程中提交AI任务。更新仍由服务器正常提供，重新打开或刷新即可获取网站更新。
- HTTPS部署可用安装功能；本地开发可使用localhost或127.0.0.1。安装按钮是否出现以及系统安装确认由浏览器决定。

## 维护说明

应用清单在`src/app/manifest.ts`，浏览器读取的`GET/HEAD /manifest.webmanifest`为公开静态元数据；页面、API及用户数据继续走原认证。安装图标使用现有`public/icons/icon.svg`生成，源标志保持不变。192/512像素PNG、512像素maskable图标及180像素Apple图标作为静态文件随部署发布，可用`node scripts/generate-install-icons.cjs`重新生成。

不引入PWA框架依赖或离线插件。今后如果需要离线使用、推送或后台同步，应单独设计，不把用户数据缓存或任务自动重发混入安装功能。

官方依据：Next.js的Progressive Web Applications指南、Chrome的PWA安装条件说明，以及Apple的iPhone网站转App使用指南。本轮实际手机安装确认仍由用户在设备上完成，浏览器自动化覆盖清单可读、图标、原生安装条件检查、登录边界和安装说明。
