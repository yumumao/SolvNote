## 真实性与边界

- 所有截图使用当前程序的隔离测试实例；题目、解答、原图、构造方案、连接及模型均为人工合成示例，不含用户数据或真实密钥。
- 截图中的公式与SVG由真实前端渲染，接口数据由本地拦截提供。未向供应商发请求，没有真实AI识图、解题或生图调用，因此不能把示例当作模型能力、正确率或生成效果证明。
- MiniMax图片展示的是配置与提示词准备，不是冒充真实生成的成品。实际API能力、计费和结果需使用者自行核对。
- PNG原始截图不进入公开仓库；公开素材压为WebP并去除元数据。设置图只裁取配置区，阅读页只裁去页面留白，没有修改界面控件或拼造产品画面。
- learning-workflow*.svg与explanation-guide*.svg是功能结构示意，不是截图；本站图标直接引用public/icons/icon.svg，不另存一份。
