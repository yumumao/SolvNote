# 旧版与多轮解题的回归审计

本次审计使用仓库提交`d75e37b`中的旧式解题源码作为基线，并对照多轮流程初版备份和当前源码。它不是对线上部署提交、私人自定义模板或真实AI调用轨迹的取证，不能据此把每次历史失败归为同一个原因。

## 为什么相同模型会出现不同表现

多轮改造不是在旧提示词后简单追加聊天记录，而是新增了结构化转录、JSON状态协议和独立解题路径。模型相同不等于提示词、上下文、任务链和返回格式相同。

| 检查项 | 旧式流程 | 多轮改造中的回归或差异 | 当前处理 |
|---|---|---|---|
| 教学要求 | 详细分析模板，题干、答案、解析等9个字段；Markdown/LaTeX | 最初新提示词较短，未完整迁移教学要求；追问可能只剩当前一句回复 | 完整题干、参考答案、解题思路、分步解答、检验与总结；追问结果仍可独立存入错题本 |
| 年级与方法 | 年级是讲解偏好，正确性优先 | 初版强调允许超出年级，但对方法递进约束不足 | 最低必要知识；可用简洁严谨的初等几何时优先，不为方便计算默认用高阶方法，也不强凑旋转或全等 |
| 答案编辑 | 原编辑器含作答状态、错答、错因、知识点与GeoGebra | 最初会话界面没有完整接入编辑器 | 完成即出现可直接编辑和添加的完整编辑器，保留公式预览及折叠源码；新回复不覆盖人工草稿 |
| 题图发送 | 有图时走视觉链；转录模式明确以原图为准并继续带图解题 | 新流程按解题链选模型，支持视觉才附图；不是所有解题模型都会收到图片 | 明确提供imageContext；未附图不等于原图不存在。多模态同时核图，文字模型可请视觉模型补读 |
| 图示证据 | 直接要求全面理解图表和约束 | 识图的missingInformation曾提前触发问人；防止按外观猜条件的措辞可能被模型扩大解释 | 清晰角弧、直角框、刻痕等是显式条件，不要求文字重复。转录疑点先交解题者核对；依据定义/定理的推导与凭外观猜测明确区分 |
| 提示词权限 | 旧分析模板直接处理题图 | 新模板将任务数据统称不可信，未区分指令权限与题设证据 | 题目不能改写系统规则，但这不代表题目事实不可信；正常读取并核对图示 |
| 澄清顺序 | 缺信息时说明不确定 | 新流程优先补读规则与结尾的不确定就请求确认冲突 | 图内可查先定向补读；确实缺材料、需要用户选择或补读仍不清才询问；不强编答案 |

以上指出的是源码变化和可能影响，不是对模型内部决策的证明。没有把某一道示例题的答案、角名或固定五步解法写进提示词。

## 图片、次数与耗时边界

- 旧新上传仍共用`processImageFile`；没有因这次提示词修复调整压缩质量、采样参数或图像序列化。
- 识图和首次多模态解题使用上传处理图；定向补读优先使用保留的原裁剪图。
- 文字解题者补读时，带具体疑问交视觉链，再交回原解题者；多模态解题者自己补读。解题和可选复核共享每轮一次自动补读额度，外发前持久化，当前轮等待与恢复不重置。
- `sourceImageAvailable`、`rereadsUsed`、`rereadLimit`只补充模型上下文，不改变数据库结构、配置交换格式或调用预算。
- 先识图再解题通常至少两次调用；文字模型补读路径通常四次。不能承诺比单次直接解题或ScanDex转录更快。
- Responses完成事件后仍等待EOF、安全出口对Fake-IP的拒绝，是另两类已单独修复的问题，不应全部归咎于提示词。

## 没有机械照搬的旧能力

旧式路径支持从配置读取自定义XML模板，并查询课程知识点目录；新多轮使用独立JSON控制协议，目前不直接套用旧XML自定义模板，也未注入同一课程标签目录。旧入口保留这些能力，新编辑器的知识点仍可修改。

不能把任意XML输出模板拼进JSON系统提示词，否则会引入相互矛盾的格式指令。若以后需要共用自定义教学风格，应将可迁移的教学内容与协议外层拆分后再设计、迁移和测试。本次未读取私人配置，不能断定任何运行实例曾使用何种自定义模板。

## 防止再次只测通路不测体验

1. 提示词回归：旧9字段、Markdown/LaTeX、教学分区、最低必要知识、图示证据、图内疑点优先补读、数据权限边界。
2. 路由回归：文字解题者明确知道原图可用，补读计数真实递增；多模态与文字模型各自路径、复核归属及额度边界。
3. 图像序列化回归：5类协议在相同模型、文本与图片下，仅替换新旧提示词不改变其他请求字段。
4. 隔离浏览器验收：直接编辑、公式预览/源码、错答/错因、知识点、GeoGebra、草稿保护、返回首页及AI设置操作。
5. 发布或重启前绑定同一构建的全量测试、类型检查、构建与浏览器报告；启动后检查实际运行构建，不能只看登录页打开。
6. 真实质量仍由同图新会话验收：图示读对、不过早问人、方法合适、步骤充分，且不编造条件。合成测试不能证明某个真实模型一定识图正确或更快。

旧会话答案不会自动重写，当前轮已用补读次数不会因升级归零。比较新提示词效果应新建同图会话，并核对调用记录中的实际模型、所属连接和是否附图。
