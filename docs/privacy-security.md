# 公开部署的隐私与安全边界

本文说明当前源码的处理方式，供开放试用前核对。运行中的镜像、反向代理、数据库、AI服务和备份策略由每个部署者负责；源码检查或测试通过不代表所有部署已经升级，也不构成零风险保证。

## 试用角色与有效期

面向普通使用者的试用账号必须为`role=user`，并另外设置`expiresAt`。角色决定权限，有效期决定何时停止访问，两者互相独立。有到期时间的管理员账号，在有效期间仍有管理员权限；为管理员设置7天或30天期限不会将其变成普通用户。

开放前在用户管理中核对账号角色、有效期、启用状态和模型授权。手动创建账号默认永久，不能直接把默认值当作试用期限。到期或禁用会阻止受保护页面和API访问；账号清理与历史备份保留是另外的过程，详见[用户系统部署说明](user-management.md)。

## 密钥与导出

站点AI密钥由服务端调用供应商时使用，普通账号的配置响应不返回这些密钥。个人AI配置与站点配置分开，个人配置也不会通过读取接口直接返回保存的密钥。

`SOLVNOTE_ENABLE_AI_CONFIG_EXPORT`默认关闭。保持不设置或设为`false`时，管理员也不能使用AI配置导出接口；只有部署者显式开启后，管理员才能导出经口令加密的站点AI配置。普通账号不能通过此开关获得管理员导出权限。公开模板不含部署密钥。

设置中的“导出我的错题本数据”包含本人资料字段、错题本、题目、标签和部分学习记录，不包含AI凭据、AI任务、解题会话或部署配置，不是完整备份。管理员另有全站学习数据导出权限。需要迁移或恢复站点时，应按部署文档配套保管数据库、配置和原秘密变量。

## 需要信任谁

站点管理员能管理账号、AI连接和站内学习数据；部署平台或数据库管理者可能接触数据库、配置、环境变量与备份。普通题目和笔记不是端到端加密，服务端加密也不意味着对服务器管理者隐藏。关闭AI配置导出不能代替管理员账号和部署账户的保护。

AI调用会把本次需要的题文、题图和会话上下文发送给选定的供应商或中转服务，鉴权密钥也会发给对应服务。只配置可信服务地址，并核对其数据保留和使用政策；上传前裁去姓名、学号等无关信息。应用不能替代供应商的安全和隐私承诺。

登录、注册使用Cloudflare Turnstile。按需打开GeoGebra或加载材料中的外部图片时，还可能连接相应外部服务。托管平台、反向代理和这些服务有各自的数据处理规则。

## 隐私页与源码入口

当前源码在`/login`、`/register`和首页页脚提供项目源码与`/privacy`链接；隐私页无需登录。登录和注册页说明：邀请码用完或试用结束后，可以获取源码自行部署并自备AI服务。点击项目链接不会自动上传学习记录，自行部署也不会自动迁移原站点的账号或资料。

部署者应在开放前确认实际站点的这些入口可用，并根据自己的AI供应商、托管平台和保留策略向用户说明隐私边界。仓库维护者无法代替其他部署者删除其用户数据。

## 日志与备份保留

本版本的浏览器诊断日志不再自动回传本站；兼容旧客户端的日志接收端不解析或保存其正文。统一应用日志保留固定事件、计数和状态标志，对自由文本上下文及错误详情做脱敏。

这些改动不覆盖托管平台、反向代理、Cloudflare或AI供应商自行保留的日志。升级不会自动清除旧版本日志、数据库历史备份或已下载的导出文件。部署者需要分别管理访问权限、保留期限和清理流程；账号或资料删除不等于所有备份立即擦除。

## 开放前的部署核对

- 确认实际运行的应用版本、基础镜像与依赖；核对安全更新和发布来源，并让程序、数据库迁移与生成的客户端配套。不能仅根据源码分支或可变镜像标签判断部署已包含某项修复。
- 确认试用账号使用普通角色，具有预期有效期和模型授权，使用独立管理员账号维护站点。
- 保持AI配置导出默认关闭，妥善保护管理员密码、部署账户、密钥和成套备份。
- 使用真实部署的登录、注册及普通账号验证权限与隐私入口；自动化合成测试不能替代生产配置验收。

上述措施减少可识别的风险，不能保证管理员终端、托管平台、第三方服务或未来代码变更永不发生泄露。
