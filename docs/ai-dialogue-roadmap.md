# 同题会话、人工澄清与多轮问答

本版同题会话已实现，并恢复完整答案直接编辑、折叠源码、最低必要知识的分步教学及设置便利性。部署需要更新镜像并完成数据库迁移；旧镜像不会自动获得这些功能。

## 一个会话覆盖整道题

从识图、解题、定向补读、人工澄清到结果追问，共用题图、转录、历史消息和调用记录。用户不是只能在失败后重开任务；可补充条件后继续当前轮。纯文字输入跳过识图。

- `vision`链用于识图和补读。
- `text`链用于解题和问答；有`vision`能力的解题者同时收图，纯文字解题者只收转录与上下文。
- 原图能查的疑点优先定向补读。文字解题者带问题给视觉模型，回到原解题者；多模态解题者自己核图。
- 清晰的角弧、直角框、等长刻痕和平行箭头本身是题设证据，不要求再写文字说明；但没有标记时不能仅凭外观或比例推断等长、垂直或平行。
- 转录中的`missingInformation`只是识图模型的判断，不直接触发人工等待；先由解题者结合可用原图和上下文核对。定向补读的转录同样回交原解题者，不让识图阶段越过解题者直接问人。
- 解题/复核返回`needs_user`时，新增可选`reason`：`missing_source`表示确认原材料真的缺失，`user_choice`表示只有用户能决定，二者直接等待；`image_unclear`或旧响应没有原因时，有题图且本轮尚未补读则先定向补读。兼容旧会话/旧响应，不改加密AI配置格式，不靠匹配中文关键词控制路由。
- 补读仍不确定才询问具体歧义，不为了自动完成编造条件。确实缺失半张题图或需要用户选择也可直接询问，不强加无效重读。识图误报缺失时现在会多经过一次解题判断，而不是提前停止。
- 每轮最多一次自动补读回环，解题与独立复核共享，额度在请求之前持久化，不因人工暂停而重置。独立复核的结论必须由不同于原解题者的模型给出；文字复核者可以调用识图链补读，再回到同一个复核者，必要时原解题模型仅以转录角色参与。复核问人时不把候选答案当最终结果展示。

## 结果仍是完整的错题本条目

每轮完整结果独立保存题干、参考答案、分步教学解析、错误作答、错因、作答状态及知识点。追问解释整合进解析，不把完整题目降成一句聊天回复。新版按区渲染Markdown/LaTeX，源码默认折叠；历史纯文本消息仍可阅读。

首页、学科添加页和独立会话页均自动挂载同一个完整编辑器，不再额外取回。作答状态、错答原文、错因和知识点可直接编辑；题干、答案和解析默认预览，源码折叠。新回复不会覆盖当前草稿，须确认采用并再次校验版本、学科归属及配对题图。会话状态刷新/追问保留草稿，但整页重载、关闭或返回首页不自动持久化人工修改，离开前提示先保存。GeoGebra仍在编辑器中，生成演示复用原队列且需主动点击。
几何题还会显示结构化角证据和独立核验状态。用户可以在同一编辑器中完整替换题目转录；人工版本会清空旧机器事实并优先用于后续解题。题目、答案或解析版本改变后，已生成的辅助线方案会被标为过期，不能直接套用。

提示词恢复旧教学规范但不照搬旧XML协议。新会话始终使用solved/needs_visual_check/needs_user三种JSON状态；转录保留学生作答证据，无依据不生成个人错因。仅改变显示不会使已生成的简短解析自动补全，也不会自动重试真实上游。

## 状态与计数

`active`表示排队或执行，`awaiting_user`等待人，`answered`本轮完成，`failed`可检查剩余预算后继续，`unknown`不允许续发，取消经过`cancelling`到`cancelled`。

首次完整答案计1轮；主动追问并获答再计1轮。澄清、纠错和补图属于当前轮，不额外占问答轮数。失败或人工等待不增加完成轮数。

| 边界 | 默认/行为 | 管理员操作 |
| --- | --- | --- |
| 问答轮数 | 新会话默认10轮；已有会话快照不被全站设置覆盖 | 默认值1–100；当前会话可确认追加，硬上限100 |
| 当前轮上游尝试 | 6次；失败、回退、补读、复核也计数 | 每次确认追加4次，硬上限18 |
| 当前轮活动时间 | 累计600秒；单次请求最多180秒且不超过剩余窗口 | 每次确认追加600秒，硬上限1800秒 |
| 自动补读 | 每轮至多一次回环 | 不因人工暂停或扩预算而重置 |
| 人工等待 | 持久保存，释放worker，不计活动时间 | 无需延长HTTP请求 |

扩额不立即调用AI。到限仍可保存人工补充，只有再次点击继续才创建执行任务。管理员权限以数据库实时角色为准，所有会话动作仍需归属校验；本轮未新增管理员跨用户浏览对话的能力。

## 持久化与安全

- `AiConversation`保存加密上下文、revision、额度与活动任务；`AiConversationAction`保存加密幂等收据；`AiDialogueSettings`保存新会话默认轮数。
- `AiJob`关联会话并保存本段开始时间；`AiAttempt.metadata`加密保存当时的模型名、实际模型、连接名、阶段、图片标记、疑点与轮次。更改配置不会把旧调用显示成新模型。
- 所有写API先认证、同源校验，再读取请求体；使用用户归属、实时账户状态、CAS和请求ID防并发覆盖及重复调用。旧短任务接口不能读写内部会话任务。
- 人工回复只用作题目条件，不作为系统指令。无跨用户题图缓存；不回显Key、原始异常、供应商原始响应或内部思维链。
- 关闭页面只停止页面轮询。worker崩溃或完成后落库失败无法确认是否已收费时标记unknown，不自动重发。取消不保证上游退款。
- 执行中轮询不反复传整张图，初次恢复及完整结果恢复时才请求配对图片。明确采用新回复时再次核对版本；不能把属于另一个错题本的会话编辑保存到当前学科页。
- 每用户最多100会话；消息最多300条/180000字符，组装上下文另有200000字符上限。到限明确停止，不悄悄删关键条件。用户可确认删除非执行中的会话，已保存错题不受影响。
- 会话不沿用旧短任务24小时清理；持久卷及主钥需配对备份。这不是整库加密，原有账户和错题存储方式未改。

## 接口与代码入口

- `POST/GET /api/ai/conversations`：创建/列表；创建返回201，不走旧202自动轮询。
- `GET/POST/DELETE /api/ai/conversations/[id]`：恢复/动作/删除；`restore=1`附图片。
- `GET/POST /api/ai/dialogue-settings`：管理员默认轮数与revision。
- `src/lib/ai-dialogue/`：协议、状态机、预算结算和恢复。
- `src/components/ai-conversation.tsx`、`conversation-answer-editor.tsx`、`ai-process.tsx`：人工操作、自动完整编辑器与事实性过程。
- `src/lib/ai-drawing/`、`src/components/auxiliary-drawing.tsx`：受限辅助线构造、GeoGebra预览和可选图片编辑队列；详见[几何辅助线与图片编辑](ai-drawing.md)。
- 首页及错题本添加页默认会话；独立页`/ai-dialogue/[id]`；统一列表`/ai-tasks`。

## 兼容与发布门槛

portable-ai-config v1结构不变，导入保留两链成员与顺序；此改动不要求ScanDex及其他消费者同步升级。不会自动把所有多模态模型加入解题链。旧式直接解题、短任务恢复和24小时保留行为仍保留。

先在临时SQLite与模拟上游中验证四次补读路径、原模型续解、停用模型、暂停/重启、幂等并发、权限、额度和unknown；隔离浏览器验证真实页面和API，但人工等待/完成状态使用合成夹具，不代表实际模型回答。

发布前仍需人工用少量真实模型与几何题验收速度、识读质量和JSON协议兼容；需明确授权才接触真实配置/题图或更换现有测试实例。上游耗时和正确率不能由合成测试证明。升级需先备份配置与数据双卷，再部署新增迁移；不删除或重建真实数据库。
